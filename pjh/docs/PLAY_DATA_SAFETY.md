## 5. 민감 권한 정당화 문구 (Play Console 요청 시 입력)

### 5.1 카메라 (`android.permission.CAMERA`)
> 사용자가 반려동물 사진을 직접 촬영하여 게시글로 업로드하거나 감정분석 기능에 사용하기 위해 필요합니다. 사진은 사용자 본인의 명시적 액션 시에만 촬영되며, 백그라운드 촬영은 일절 수행하지 않습니다.

### 5.2 위치 (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)
> 사용자 주변의 동물병원을 검색하고 거리순으로 정렬하기 위해 사용합니다. 위치 정보는 동물병원 검색 화면 진입 시 1회 조회되며, 백그라운드 위치 추적이나 서버 저장은 수행하지 않습니다.

### 5.3 알림 (`POST_NOTIFICATIONS`)
> 본인 게시글에 대한 댓글/좋아요, 1:1 채팅 메시지, 앱 운영 공지 등 사용자가 구독한 활동에 대해 푸시 알림을 발송하기 위해 사용합니다. 알림 종류별 on/off는 앱 내 알림 설정에서 사용자가 직접 제어할 수 있습니다.

### 5.4 미디어 이미지 읽기 (`READ_MEDIA_IMAGES`)
> 갤러리에서 반려동물 사진을 선택하여 게시글 또는 감정분석에 사용하기 위해 필요합니다. 사용자가 직접 선택한 사진만 접근하며, 갤러리 전체를 스캔하지 않습니다.
