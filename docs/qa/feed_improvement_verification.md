## 0. ⛔ 선행 — posts_category.sql 적용 확인 (Q&A 동작 전제)
1. 🟦 Supabase SQL Editor에서 `supabase/migrations/posts_category.sql` 실행.
2. 컬럼 생성 확인:
   ```sql
   SELECT column_name FROM information_schema.columns
   WHERE table_name='posts' AND column_name='category';
   ```
   **합격:** `category` 1행 반환.
3. 📱 미적용 상태로 Q&A 탭 진입 시 → 조회 에러(빨간 스낵바/빈 목록). 적용 후 정상.

> 이 단계가 끝나야 1~5 검증이 의미 있음.

## 1. Q&A 페이지네이션 (무한 스크롤)
1. 📱 Q&A 모드 → '전체' 탭. 글이 30건 이상이도록 더미 작성(또는 시드).
2. 아래로 스크롤 → 30건 경계에서 다음 페이지가 자동 로드되어 이어붙는지.
   **합격:** 31번째 이후 글이 끊김 없이 로드(하단 로딩 인디케이터 후 추가). 중복 없음.
3. 더 내려 마지막 도달 → 추가 로드 멈춤(hasReachedMax).

## 2. 상태 보존 (탭 재진입·모드 토글)
1. 📱 Q&A에서 여러 페이지 스크롤 → 사진 모드로 토글 → 다시 Q&A.
   **합격:** 이전에 로드된 목록·스크롤 위치가 유지(처음부터 다시 로드 안 함).
2. (앱 구조상 페이지 재생성 시엔 재로드 — Cubit이 page 트리에 살아있는 동안만 보존.)

## 3. 카테고리 필터 (category 컬럼 기반)
1. 📱 '건강' 칩 탭 → 건강 글만 표시. '훈련'·'먹거리'·'생활'도 각각.
   **합격:** 선택 카테고리 글만(다른 카테고리·미분류 제외).
2. DB 대조:
   ```sql
   SELECT count(*) FROM posts
   WHERE post_type='community' AND category='health' AND deleted_at IS NULL;
   ```
   화면 건수와 일치(매거진 제외).
3. 칩 시각화: 선택 시 카테고리 컬러 채움(건강=딥블루·훈련=퍼플·먹거리=앰버·생활=틸).

## 4. post_type 오염 차단
1. 📱 사진 글(post_type=photo)이 우연히 `health` 등 hashtags를 가져도 **Q&A 목록에
   안 뜨는지** 확인. (Q&A 조회에 `post_type='community'` 필터.)
   **합격:** 사진 글은 Q&A에 비노출. Q&A엔 community 글만.
2. (반대쪽 — Q&A 글이 사진 피드에 섞이는 건 이번 범위 밖, 사진 피드 무변경.)

## 5. 빈 상태 CTA
1. 📱 글이 0건인 카테고리 진입 → 일러스트(💬+✏️) + "첫 글 쓰기" 버튼.
2. "첫 글 쓰기" 탭 → 글쓰기 화면 진입 → 작성 → 목록 자동 갱신.
   **합격:** CTA가 글쓰기로 연결, 작성 후 즉시 반영.

## 6. 매거진 노출
1. 🟦 사전: 운영자 글(hashtags에 `magazine`) 1건 이상 존재.
2. 📱 Q&A '전체' 탭 상단에 "📰 매거진" 가로 카드 슬라이더.
   **합격:** 매거진 글이 카드로 노출, '더보기' → `/hashtag/magazine`.
3. 매거진 글 0건이면 섹션 미노출(빈 카드 없음).
4. 다른 카테고리 탭(건강 등)에선 매거진 섹션 미노출('전체'에서만).

## 7. 사진 그리드 토글
1. 📱 사진 모드(추천·팔로잉 각각) 상단 우측 리스트/그리드 토글.
2. 그리드 선택 → 3열 정사각 썸네일. 셀 탭 → 게시물 상세.
   **합격:** 이미지 있는 글만 그리드에 표시(텍스트 글 제외). 여러 장은 collections 아이콘.
3. 리스트로 복귀 → **기존과 100% 동일** 동작(아래 8 회귀).

## 8. 리스트 뷰 무변경 (회귀)
1. 📱 리스트 모드에서: 무한 스크롤·당겨서 새로고침(햅틱)·좋아요·댓글 이동·
   공유·수정/삭제·네트워크 에러·빈 상태 — **개선 전과 동일**하게 동작.
   **합격:** 리스트 동작에 어떤 차이도 없음(토글 바만 상단에 추가됨).

## 9. 그리드 무한 스크롤 (원본 기준)
1. 📱 그리드 모드에서 아래로 스크롤.
   **합격:** 사진 글이 적어도 다음 페이지(원본 posts)가 계속 로드되어 그리드가 채워짐.
   (페이지네이션은 필터된 부분집합이 아니라 **원본 posts·스크롤 기준**으로 트리거.)
2. 그리드인데 사진 글 0건 → "표시할 사진이 없어요 + 리스트로 보기" 안내.
