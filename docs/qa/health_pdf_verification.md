# 건강 요약서 PDF 검증 가이드

건강관리 PDF 내보내기(온디바이스 생성·공유)의 검증 절차. 실기기 검증 묶음 항목.

- 대상 커밋: `health-STEP4`
- 패키지: `pdf` + `printing`(네이티브 의존 — Android/iOS 빌드 필요)
- 폰트: Pretendard(assets/fonts) 임베드 — 한글 깨짐 방지

---

## 1. 패키지·빌드
- [ ] `flutter pub get` 성공(pdf·printing 해소)
- [ ] `flutter analyze` 0
- [ ] Android 릴리스 빌드: `flutter build apk --release --split-per-abi` 성공(printing AAR 링크)
- [ ] (mac 트랙) iOS 빌드: `flutter build ios` 성공(printing CocoaPods)

## 2. 진입·예외 처리
- [ ] 건강관리 AppBar의 "PDF 내보내기"(📄) 버튼 노출
- [ ] 펫 미선택 시 → "반려동물을 먼저 선택해주세요" (PDF 미생성)
- [ ] 기록 0건 시 → "내보낼 건강 기록이 없습니다" (PDF 미생성)

## 3. 생성·공유
- [ ] 기록 있는 펫 선택 → "PDF 내보내기" → **공유 시트** 표시(저장/카톡/메일/프린트)
- [ ] 저장된 PDF 열기 → **한글 정상 표시**(헤더·표·라벨 깨짐 없음)
- [ ] 파일명 `{펫이름}_건강요약서.pdf`

## 4. 내용 정확성 (한 장 요약서)
- [ ] 헤더: 펫(이름·종·품종·나이·성별)·보호자·생성일
- [ ] 체중 추이: 현재 체중 + 증감(+/-kg, %) + 표(날짜·kg·BCS), 최신순
- [ ] 예방접종: 백신·접종일·다음 예정일
- [ ] 투약: 약명·용량·주기·기간
- [ ] 검진/수술: 구분·날짜·병원·내용(최신순)
- [ ] 최근 AI 감정 분석: 분석일·대표감정·긍정도(있을 때만)
- [ ] **데이터 없는 섹션은 표가 아예 안 나옴**(빈 표 나열 금지). 전체 0건이면 "아직 건강 기록이 없습니다"

## 설계 메모
- **차트 이미지 대신 표**: fl_chart 위젯을 PDF에 이미지로 넣으려면 오프스크린 렌더·캡처가 필요해 복잡·비결정적 → 체중은 **표 + 현재값·증감 텍스트**로 대체(단위 테스트 가능, 결정적).
- **온디바이스 생성**: 서버 미경유(건강 개인정보 보호). `Printing.sharePdf(bytes)`.
- **AI 분석 요약 포함**: 펫페이스 차별점. `getAnalysisHistory(limit:1)` 읽기 전용, 금지 파일 무관.
