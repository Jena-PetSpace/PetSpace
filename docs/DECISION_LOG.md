## 2026-07-13 — 홈·AI 분석 제외 UI/UX 개선 진행 권한

- 상태: 승인
- 결정자: 황정현 CTO
- 관련 작업지시서/이슈: 정리 완료 후 생성할 UI/UX 감사서와 단계별 작업지시서
- 확인된 사실과 제약: 현재 UI가 화면별로 서체·크기·색·간격과 컴포넌트 사용이 일관되지 않아 신뢰도가 낮다. 홈 화면과 AI 분석 화면은 이번 수정 대상이 아니다.
- 검토한 선택지: 화면별 즉시 수정, 코드 감사와 레퍼런스 확인 뒤 디자인 시스템 및 기능군별 단계 구현
- 최종 결정: 실제 `/home` 본체인 `pjh/lib/features/social/presentation/pages/home_page.dart`, 그 하위 홈 위젯인 `pjh/lib/features/home/**`, AI 분석 화면군인 `pjh/lib/features/emotion/presentation/**`는 직접 수정하지 않는다. 나머지 전체 화면은 코드 감사, Claude에 전달된 레퍼런스 확인, 기획서·작업지시서 작성, Claude Opus 4.8·Codex 토론과 동일 범위 합의 순서로 진행한다. 양쪽 합의와 `blocker/high` 부재가 확인된 각 작업 단계는 별도 사용자 중계 없이 구현할 수 있다.
- 선택 이유: 대규모 시각 변경을 검증 가능한 작은 단계로 나누고, 기존 기능을 보존하면서 브랜드 신뢰도와 일관성을 높이기 위해서다.
- 영향받는 코드·문서: 보호 경로를 제외한 presentation UI와 공용 디자인 토큰·컴포넌트. 공용 변경이 보호 화면에 미치는 영향은 회귀 검증한다. 라우팅·상태·비즈니스 로직·법적 문구·DB·외부 API 계약은 별도 합의 없이는 변경하지 않으며 merge, push, deploy도 하지 않는다.
- 재검토 조건: 레퍼런스를 찾지 못함, 보호 화면 직접 수정 필요, 기능 동작 변경, 보안·법무·데이터 변경, 양쪽 의견 불일치 또는 `blocker/high` 발생
