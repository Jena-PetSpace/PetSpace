## 설명 초안

펫페이스는 반려동물의 일상과 건강 기록을 한곳에 모으고, 사진을 바탕으로
감정과 건강 신호를 살펴볼 수 있는 반려생활 앱입니다.

주요 기능:

- 사진 기반 반려동물 감정 분석
- 사진 기반 건강 신호 확인
- 건강 일정과 기록 관리
- 산책과 일상 기록
- 피드·커뮤니티 게시글, 댓글, 좋아요, 팔로우
- 사용자 신고·차단과 개인정보 공개 범위 관리
- 1:1 메시지와 알림

AI 분석 결과는 수의학적 진단이나 치료를 대신하지 않는 참고 정보입니다.
증상이 있거나 건강이 염려되는 경우 수의사와 상담해주세요.

## 스크린샷 기획

사용자가 최신 소개 이미지를 전달한 뒤 실제 출시 빌드와 일치하도록 다시
제작한다. 현재 universal target이므로 iPhone뿐 아니라 iPad 제출 요구도
확인해야 한다.

권장 iPhone 순서:

1. 펫페이스 핵심 가치
2. 감정 분석
3. 건강 신호 분석
4. 건강 기록·일정
5. 피드·커뮤니티
6. MY·반려동물 관리

주의:

- 분석 결과를 진단·치료·정확도 보장으로 표현하지 않는다.
- 특허, 최초, 무료, 비용 없음 등의 문구는 증빙과 실제 정책 확인 전 사용하지
  않는다.
- 화면은 제출하는 build와 일치해야 한다.
- 알림, 시간, 계정명, 사용자 사진 등 개인정보를 제거한다.
