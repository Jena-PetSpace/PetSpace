# PetSpace iOS 출시 준비 1단계 — 기술 사실·사용자 결정 매트릭스

기준일: 2026-08-09
기준 브랜치: `mac-ios-release`
기준 커밋: `1962aa63625d06f79d1398ef85f6f0191d0d5d31`
상태: `PARTIALLY_APPROVED`

## 목적

공개 개인정보처리방침·이용약관·지원 페이지를 만들기 전에 앱, iOS Privacy
Manifest, Supabase 스키마와 현재 법적 문서의 기술적 사실을 맞춘다. 이 문서는
법률 자문을 대체하지 않으며, 법적 최종 문구는 회사의 검토·승인이 필요하다.

비밀 파일, Firebase 설정 내용, 인증서·키·프로비저닝 프로파일은 읽거나
기록하지 않았다.

## 현재 문서의 출시 차단 불일치

### P0

1. 광고 도입은 결정됐지만 공급자와 맞춤형 광고 여부가 미정이다. 현재
   `docs/legal/privacy_policy_v6.md`는 IDFA 수집 가능성을 기재하고 앱과
   Privacy Manifest는 추적하지 않는다고 선언한다.
2. 사용자 휴대전화번호와 결제·신용카드 정보를 수집한다고 기재하지만 출시
   앱의 수집 경로가 확인되지 않는다.
3. 현재 플레이스는 장소명·주소·링크를 공유하며 사용자의 실시간 위치를
   타 사용자에게 공유하지 않는다. 정책의 실시간 위치 공유 문구는 과장이다.
   반면 주변 검색을 위한 정확한 위치의 Kakao 처리 경로는 명시해야 한다.
4. 자체 AI 도입은 예정됐지만 이용약관이 이미 사용자 콘텐츠를 자체 AI 모델
   학습·가중치에 사용할 수 있다고 기재한다. 실제 기술 흐름과 명시적 선택
   동의가 구현되기 전에는 완료된 처리로 공개할 수 없다.
5. 가입 화면에서 마케팅 동의는 기록하지만 설정 화면에는 독립적인 마케팅
   수신 동의 조회·철회 경로가 없다.
6. 공식 지원 이메일은 사용자 지정 주소로 통일하기 시작했다. 공개 페이지와
   App Store Connect에서도 같은 주소를 사용해야 한다.
7. `https://petspace.app/privacy`, `/terms`, `/support`는 실제 문서가 아닌
   `/lander` 주차 페이지로 연결된다.

### P1

1. Google AI, Supabase, Firebase의 국외 이전 국가·보유기간·학습 사용 여부를
   실제 계약과 운영 설정에 맞춰 법률 검토해야 한다.
2. 위치정보 이용·제공사실 확인자료 6개월 보존과 일반 좌표 삭제 시점이 운영
   migration·purge·cron에서 실제 활성화됐는지 확인해야 한다.
3. 지원 페이지에 회사명, 문의 이메일, 답변 가능 시간, 개인정보·계정 삭제
   문의 경로를 공개해야 한다.

## 역할 분담

### Codex가 사용자 결정 후 수행

1. 개인정보처리방침 v7, 이용약관 v8, 위치약관 v6 초안 작성
2. 앱 내부 `LegalDocuments`와 `docs/legal` 정본 동기화
3. 미사용 IDFA·전화번호·결제·실시간 공유·AI 학습 문구 제거
4. 마케팅 동의 UI·DB 처리의 출시 범위 정리와 계약 테스트 추가
5. `/privacy`, `/terms`, `/support` 정적 페이지와 모바일 대응 UI 작성
6. 공개 페이지와 앱 내부 문서 내용·버전·시행일 자동 검증 추가
7. App Store 개인정보 답변표와 심사 메모 갱신

### 사용자가 직접 수행하거나 확정

1. 광고 공급자, 맞춤형 광고 여부, 출시 국가 확정
2. 자체 AI의 입력 데이터, 학습/추론 구분, 보유기간, 삭제·동의 방식 확정
3. 회사 공식 연락처, 개인정보 보호책임자, 회사 주소의 공개 가능성과 정확성 확인
4. 법률 전문가 또는 회사 책임자의 최종 문구 승인
5. `petspace.app` DNS·호스팅 계정 접근 제공 또는 직접 배포
6. 공개 페이지가 외부 네트워크에서 열리는지 최종 확인

## 다음 단계 진입 조건

광고 공급자·맞춤형 광고 여부와 자체 AI 데이터 계약이 확정되면 2단계에서
법적 문서 초안과 배포 가능한 정적 페이지를 작성한다. 공개 배포는 사용자
법적 승인과 호스팅 접근이 확인된 뒤에만 한다.
