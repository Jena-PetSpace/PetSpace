## 설명

펫페이스는 반려동물의 일상과 건강 기록을 모으고, 사진을 바탕으로 감정과
건강 신호를 살펴볼 수 있는 반려생활 앱입니다.

주요 기능:

- 사진 기반 반려동물 감정 분석
- 사진 기반 건강 신호 참고 분석
- 건강 기록과 다음 일정 관리
- 반려동물 프로필과 대표 반려동물 관리
- 피드·커뮤니티 게시글, 댓글, 좋아요, 팔로우, 저장
- 1:1 메시지와 알림
- 사용자 신고·차단과 개인정보 보호 설정
- 주변 동물병원·반려동물 장소 검색
- 반려동물 MBTI, 퀴즈와 운세

AI 분석 결과는 수의학적 진단이나 치료를 대신하지 않는 참고 정보입니다.
증상이 있거나 건강이 염려되는 경우 수의사와 상담해주세요.

## 심사 메모 핵심

1. AI 결과는 참고 정보이며 진단·치료 기능이 아닙니다.
2. 위치는 주변 장소 검색과 사용자가 선택한 게시물 장소 첨부에 사용합니다.
3. UGC에는 신고·차단·콘텐츠 필터·운영 가이드라인이 있습니다.
4. 회원탈퇴는 앱 설정에서 시작하며 30일 복구 유예 후 삭제 계약을 적용합니다.
5. 심사용 계정은 App Store Connect의 비공개 Review Information에만 입력합니다.
