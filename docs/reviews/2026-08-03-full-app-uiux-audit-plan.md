# PetSpace 전 화면·전 기능 UI/UX 감사 및 개선 계획

기준일: 2026-08-03
대상: iOS 우선, 공통 Flutter 화면은 Android 동시 정합성 검토
구현 원칙: 화면별 목업과 사용자 승인 전 대규모 UI 변경 금지

## 감사 방식: 3회 독립 검토

### 1차 — 정보 구조·사용자 여정

- 진입점, 뒤로가기, 취소, 저장, 재시도, 완료 후 다음 행동을 확인한다.
- 동일 기능의 중복 화면·용어·CTA를 찾는다.
- 처음, 빈 상태, 로딩, 성공, 부분 성공, 오프라인, 권한 거부, 서버 오류,
  세션 만료 상태를 분리한다.

### 2차 — 시각·인터랙션·접근성

- 배경·surface·테두리·간격·타이포·아이콘·버튼 위계를 대조한다.
- 44pt 터치 영역, Dynamic Type 200%, VoiceOver, 다크 모드, 키보드,
  iPhone 소형 화면, iPad 세로·가로·Split View를 검증한다.
- 장식성 이모지, 의미 없는 카드 중첩, 과한 그림자·그라데이션,
  바닥 고정 CTA의 이중 safe area를 제거 후보로 분류한다.

### 3차 — 기능·백엔드·신뢰성

- 낙관적 UI와 서버 정본의 불일치, 중복 탭, 재시도 멱등성, pagination,
  realtime echo, 권한·네트워크 복구를 확인한다.
- 사용자 데이터·토큰·알림 본문·위치·원문 오류가 로그에 노출되지 않는지
  확인한다.
- iOS HIG와 Material 동작 차이는 공통 디자인을 유지하면서 플랫폼별
  권한·뒤로가기·공유·로그인 동작으로 분리한다.

## 전 화면 인벤토리

### A. 인증·온보딩

- Splash, 소개 슬라이드, 로그인/회원가입, 아이디 찾기
- 이메일 인증, Kakao 동의, 약관 동의·상세
- 프로필 설정, 첫 반려동물 등록, 튜토리얼, 완료
- 비밀번호 재설정 요청·코드 확인·새 비밀번호

중점: 소셜 로그인 우선순위, 오류 위치, 키보드, 복구, 법적 동의,
중복 제목·버튼, 계정 삭제/복구 문구.

### B. 메인 내비게이션

- 홈, 건강, AI 분석, 피드/커뮤니티, MY
- 탭 배지, 딥링크, 탭 복귀 상태, 스크롤 위치, 대표 반려동물 범위

중점: 탭별 헤더 규칙, 하단바 AI 발바닥 아이콘, 배지 접근성,
중복 진입점과 탭 간 시각 언어.

### C. 반려동물

- 목록/관리, 등록, 수정, 상세, 공개 프로필, 대표 반려동물 변경

중점: 등록 단계 수, 사진 실패 복구, 삭제 위험도, 초대/소유권 문구,
0마리·다견 상태와 대표 선택의 즉시 반영.

### D. 피드·커뮤니티·소셜

- 피드 허브, 탐색, 검색, 사진 글·커뮤니티 글 작성
- 게시글 상세, 수정·삭제, 댓글·답글, 좋아요 목록
- 저장·컬렉션, 해시태그, 장소 글, 알림
- 팔로워·팔로잉, 사용자 프로필, 신고·차단·차단 해제

중점: 사진 글과 커뮤니티 글 작성 정본, 공개 범위, 임시저장,
미디어 실패, UGC 안전, pagination, realtime, 빈 상태 CTA.

### E. 채팅

- 채팅방 목록, 새 채팅, 상세, 입력/첨부, 신고, 방 설정

중점: 전송 중·실패·재전송, 중복 전송, 읽음·배지, 차단 반영,
키보드와 입력창 safe area, 긴 메시지·이미지·오프라인.

### F. 건강

- 건강 메인, 필터, 기록 작성·수정·삭제
- 예정 알림 설정, 체중/감정 추세, PDF 미리보기·저장·공유

중점: 의료 오인 방지, 날짜·단위, 대표 반려동물 범위, 기록 없음과
조회 실패 구분, 알림 권한 복구, PDF 생성 실패.

### G. AI 감정·건강 분석

- 분석 선택/입력, 촬영 가이드, 카메라, 이미지 선택
- 로딩, 감정 결과, 건강 결과, 기록, 타임라인, 추세, 주간 보고서, 공유

중점: 입력 품질 가이드, 업로드/분석 취소·재시도, 비반려동물 사진,
결과의 정보 위계와 참고 고지, 저장 상태, 민감 이미지 보호.

### H. 참여 기능

- MBTI 테스트·결과·호환·공유
- O/X 퀴즈 진행·결과·복습
- 오늘의 운세·공유, 뉴스, 리워드/배지

중점: 진행 저장, 중복 보상, 결과 신뢰 표현, 공유 카드, 광고/보상 문구,
MBTI 질문 길이·선택 상태·결과 재검사 경로.

### I. MY·설정·법적 화면

- MY 프로필·통계·대표 반려동물·내 글·저장
- 프로필 편집, MY 설정, 알림 설정, 개인정보/차단 목록
- 도움말, 커뮤니티 가이드라인, 앱 정보, 라이선스, 약관/개인정보

중점: 섹션 구분, 통계 실패, 저장/편집 정본, 시스템 권한과 앱 설정의
차이, 로그아웃·회원탈퇴, 버전·지원 경로.

## 현재 확인된 우선 개선 후보

### P0 — 출시 신뢰·안전

- QA 계정 2개로 로그인 후 핵심 상호작용을 실제 수행해야 한다.
- 실제 Apple/Google/Kakao OAuth, Apple 탈퇴 revoke, APNs를 검증해야 한다.
- FCM 서비스와 realtime 서비스의 알림 제목·본문·payload 개발 로그를
  release에서 제거하거나 비식별 이벤트로 바꿔야 한다.
- Android release debug-signing 폴백을 제거해야 한다.
- 권한 거부·영구 거부와 네트워크/세션 오류가 빈 상태로 보이지 않게 한다.

### P1 — 핵심 사용성

- 피드/커뮤니티 작성·수정·임시저장·장소·사진 흐름을 한 규칙으로 맞춘다.
- 알림 목록·설정·배지·딥링크의 용어와 읽음 반영을 통합 검증한다.
- 채팅 전송 실패·차단·키보드 레이아웃을 실제 두 계정으로 검증한다.
- 건강 기록과 대표 반려동물 변경의 화면 간 즉시 동기화를 확인한다.
- MY 상단 카드와 본문 탭의 밀도·섹션 위계를 실제 콘텐츠 상태별로 재검토한다.

### P2 — 기능별 완성도

- MBTI: 질문 진행률, 선택 확신, 중단 복구, 결과/재검사/공유 위계.
- O/X 퀴즈: 정답 색 외 단서, 해설 읽기, 다음 CTA, 결과 복습.
- 운세·뉴스·리워드: 핵심 기능과 보조 콘텐츠의 시각적 우선순위 조정.
- PDF·공유 카드: 작은 화면, 긴 이름, 다크 모드, 저장/공유 실패 복구.

### P3 — 전역 폴리시

- iPad 로그인 화면의 넓은 하단 여백은 blocker는 아니지만 전용 일러스트나
  수직 균형 목업을 비교한다.
- 공통 빈 상태에서 장식 이모지를 사용하지 않고 제목·설명·행동만 유지한다.
- 카드 중첩, surface 색상, 테두리, 8/12/16/24 간격 토큰을 통일한다.
- 스크롤 화면과 하단 고정 CTA의 safe area 소유자를 하나로 고정한다.

## 구현 Wave와 승인 게이트

| Wave | 범위 | 산출물 | 구현 전 승인 |
|---|---|---|---|
| W0 | QA 계정·기기·데이터 준비 | 상태별 캡처 기준 | 필요 |
| W1 | 인증·온보딩·설정·알림 | iPhone/iPad 목업 | 필요 |
| W2 | 피드·커뮤니티·소셜·채팅 | 두 계정 시나리오+목업 | 필요 |
| W3 | 반려동물·건강 | 기록/권한/오류 목업 | 필요 |
| W4 | AI 입력·기록·결과 | 입력/결과 정보 구조 목업 | 필요 |
| W5 | MBTI·퀴즈·운세·뉴스·리워드 | 기능별 전/후 목업 | 필요 |
| W6 | 접근성·다크모드·iPad·회귀 | 최종 diff·테스트 manifest | 필요 |

각 Wave는 `현행 캡처 → 문제 근거 → A/B 목업 → 사용자 선택 → 정확한
파일 manifest → 구현 → 관련 테스트 → 전체 테스트 → Simulator/실기기
재확인` 순서로 진행한다.

## 사용자가 준비할 항목

- 비운영 QA 계정 2개와 서로 팔로우·채팅 가능한 테스트 데이터
- 실제 Apple·Google·Kakao 로그인은 Simulator/실기기에 사용자가 직접 입력
- 실제 iPhone과 iPad, Android 기기 각 1대 이상
- 알림·OAuth·Edge 검증에 필요한 콘솔 접근과 운영 적용 승인
- W1부터 Wave별 목업 선택

계정·키·인증서·사용자 데이터는 문서, Git, 외부 리뷰 번들에 포함하지 않는다.
