# 2026-07-31 출시 준비 UI 목업

상태: 사용자 승인 대기
구현 범위: 홈 화면과 AI 분석 결과 화면 제외

## A. 앱 정보·오픈소스 라이선스

파일: `A-app-info-licenses-v5.png`

고정 계약:

- 설정에서 `앱 정보`와 `오픈소스 라이선스`를 별도 메뉴로 제공
- 런타임 버전은 `package_info_plus`로 표시
- 패키지·라이선스는 `LicenseRegistry.licenses`에서 생성
- 라이선스 원문은 생략·변형하지 않고 세로 스크롤로 표시
- 320×568, 글자 200%에서도 긴 패키지명과 영문 원문이 가로로 잘리지 않음
- 로딩, 실패, 다시 시도 상태 제공
- 태그라인은 `반려동물의 일상과 AI 참고 분석을 한곳에서`로 통일

## B. 반려동물 관리·안전 행동

파일: `B-pet-management-v2.png`

고정 계약:

- 현재 대표·삭제 대상은 `보리`, 비대표 후보는 `호두`
- 이름을 문장과 분리해 조사 오류 제거
- 대표 변경 뒤 기존 삭제 대상의 삭제 확인으로 복귀
- 대표 반려동물 삭제 정책 자체는 변경하지 않음
- 행동은 세로 배치하고 최소 44pt 유지
- 320×568, 글자 200%에서 본문 스크롤과 모든 행동 유지
- 이름·더보기 버튼에 결합된 접근성 라벨 제공
- `대표 반려동물`, 해요체로 용어·문체 통일

## C. 장소 선택·지도 실패 복구

파일: `C-location-recovery-v2.png`

고정 계약:

- 지도 실패·재시도 소진 시 지도와 `DraggableScrollableSheet` 완전 제거
- 고정 list-only 화면에서 초기, 0건, 검색 실패, 단일 선택 상태 분리
- 최근 검색 기능은 새로 추가하지 않음
- 공개 고지는 잠금이 아닌 정보 아이콘 사용
- `장소는 1곳만 선택할 수 있어요`와 라디오 단일 선택 사용
- 상단 크롬은 스크롤·축약 가능, 결과 목록은 유연 영역
- 하단 행동은 `SafeArea` 안에서 키보드 위에 유지
- 선택 상태는 배경, 좌측 바, 라디오, `Semantics(selected: true)`를 함께 사용
- 좌표 절삭 근거가 생기기 전에는 대략적 위치만 공개한다고 약속하지 않음

## Claude 협업 기록

Claude 1차 검토는 B의 후보 역할·삭제 복귀·200% 행동 배치와 C의 상태
구분·공개 아이콘·단일 선택·키보드 오버플로를 `CHANGES_REQUIRED`로
판정했다. v2는 해당 항목을 모두 반영했다.

Claude Desktop의 파일 선택 캐시가 이전 이미지 파일을 반복 첨부하여 v2
픽셀 최종 판정은 완료하지 못했다. 잘못 첨부된 이미지에 대한 판정은
폐기했으며, 비밀값·코드·사용자 데이터는 전송하지 않았다. 구현 전 사용자
승인 후 실제 위젯 테스트와 시뮬레이터 캡처로 계약을 다시 검증한다.
